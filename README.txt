PriceLabs prototype kit — packaged from the Prototype Gallery.

Work on this folder in Claude Code: CLAUDE.md, design-system-v2.md and
tokens.css are included so Claude knows the PriceLabs design rules.

Open any .html file; the Dynamic Pricing menu navigates between the
pages in this folder (links were rewired at download time).

Font Awesome is REQUIRED: icons load from the PriceLabs FA Pro kit
(kit.fontawesome.com/46535d3fdd.js) and need an internet connection.
If icons are missing, serve the folder (python3 -m http.server) or
work on the files inside Claude Code.

Source: https://github.com/abhijith-pricelabs/prototypes
